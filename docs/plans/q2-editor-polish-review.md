# Q2.4 typography, toolbar and keyboard review

Date: 2026-10-10. Implemented and validated locally. This record does not certify production accessibility or provider services.

The editor keeps the current CV picker, Undo, Design & templates and Export in its primary action row. More tools reveals three named groups: Manage CV, Writing tools and Fictional examples. The disclosure uses a button with expanded/controlled state, remains in normal document flow, and closes with Escape while restoring focus. Existing actions retain their save, ownership, provenance and export policies. Export remains a native disclosure with ordinary tab navigation, Escape/blur closure, and disabled actions while work is busy.

Source Sans 3 styles product controls; Source Serif 4 styles public/workspace display headings. Both are unmodified, pinned Adobe WOFF2 assets with their upstream SIL Open Font License notices, served through `next/font/local`. Build and browser visits need no font service. [Asset provenance and hashes](../../src/app/fonts/README.md) records the exact sources and combined 246,448-byte font payload. Saved resume fonts and preview/print metrics remain separate; renderer font embedding belongs to Q3.

The toolbar now uses at least 14px text and 44px control heights at 360/768/1440px. Mobile editor fields use 16px text. Section navigation, header controls, preview actions and card actions have larger targets. A workspace skip link, selected-section semantics, visible blue focus outlines, readable editor placeholders and a photo-upload focus outline improve navigation. Reduced motion disables chrome transitions and smooth preview-to-field scrolling. Preview keyboard selection focuses the matching contact field or the first editable field in a selected entry.

A shared focus lifecycle covers Design, shortcuts, pricing, content review, job tailoring, cover letter, history, practice generation, the demo gallery, Add Section and import review. It filters unavailable controls, wraps Tab/Shift+Tab, prevents background focus, closes the top dialog on Escape and returns focus to its launcher. It retains the launcher through React development effect replay and workspace inertness. The demo gallery can open above Design and return there after cancellation. Import review is outside the inert workspace so its review/cancel controls remain usable. Global document Undo is blocked while Design, practice generation or the gallery is open, as it already was for the other editor overlays.
